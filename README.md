<br/>

An end-to-end stock price prediction system combining historical market data, technical indicators, and multiple ML models, wrapped in an interactive Streamlit dashboard.

| | |
|---|---|
| **Stack** | Python, Pandas, NumPy, Scikit-learn, TensorFlow/Keras, XGBoost, Streamlit, Plotly, yfinance |
| **Scale** | Multi-model pipeline (Linear Regression → LSTM/GRU) |

| **Security** | No external data write access; local/session-scoped data handling |
| **Impact** | Adds a Buy/Hold/Sell recommendation engine, news-sentiment NLP layer, and risk analysis (volatility, Sharpe ratio) |
| **Built With** | 🤖 Claude |

Designed to go beyond a basic predictor — SHAP-based explainability makes model decisions transparent rather than a black box.
